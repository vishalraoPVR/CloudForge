# CloudForge-End-to-End-Azure-DevSecOps-Platform
CloudForge is an end-to-end Azure DevSecOps platform automating infrastructure provisioning, CI/CD pipelines, security scanning, and Kubernetes deployments. Built using OpenTofu, GitHub Actions, Docker, Helm, and Argo CD, it enables secure GitOps-based deployments, application networking, and continuous monitoring with Prometheus and Grafana.
